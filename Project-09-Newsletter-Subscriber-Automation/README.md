# 📌 Project Overview

The Newsletter Subscriber Automation streamlines the process of collecting newsletter subscribers and sending welcome emails automatically.

Instead of manually recording subscriber information and sending individual emails, this workflow automatically captures subscriber details from Google Forms, stores the information in Google Sheets, and immediately sends a personalized welcome email using Gmail.

This automation demonstrates how simple workflows can improve customer experience while reducing repetitive administrative work.

---

# 🎯 Business Problem

Many small businesses manually manage newsletter subscriptions by:

- Recording subscriber information manually
- Maintaining spreadsheets by hand
- Sending welcome emails individually
- Risking delayed responses
- Spending unnecessary time on repetitive administrative tasks

As the number of subscribers grows, these manual processes become inefficient and increase the possibility of errors.

---

# 💡 Solution

I designed an automated subscriber management workflow using Make.com that handles the entire subscription process automatically.

Once a visitor submits the newsletter form, the automation:

- Captures subscriber information
- Stores subscriber details in Google Sheets
- Sends an automatic welcome email
- Creates an organized subscriber database

The entire process happens in seconds without manual intervention.
